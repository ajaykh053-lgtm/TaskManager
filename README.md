# 📋 Task Manager

Task Manager is a lightweight, browser-based task tracking application built as a front-end web project. It provides a simple and intuitive Kanban-style interface to help users organize their work across three stages:
```
Task — Lists all newly added to-do items
In Progress — Tracks tasks currently being worked on
Done — Marks completed tasks
```
# ✨ Features

Add new tasks instantly using the Add Task form
Visual task count for each stage (Task / In Progress / Done)
Clean, minimal UI with no backend or login required
Fully responsive — works on both desktop and mobile browsers

# 🛠️ Tech Stack
HTML — Page structure
CSS — Styling and layout
JavaScript — Dynamic task creation and state management
